# Font licenses

All font files under this directory are redistributed under their upstream open-font licenses
(SIL OFL 1.1, Apache 2.0, or MIT as applicable).

Sources are primarily Fontsource / Fontsource Variable packages which redistribute official releases.
Hack is sourced from the `hack-font` npm package (MIT / Bitstream Vera lineage).

When redistributing DBO Studio, keep this notice. Do not sell the font files as a standalone product
where OFL restricts that.
